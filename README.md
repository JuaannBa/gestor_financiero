# Gestor Financiero

Multi-user personal finance manager — Django REST Framework backend + React SPA.

**Status:** in development (see [PLAN.md](PLAN.md) for the full plan and phases).

## Stack

- **Backend:** Django 6.0 + DRF 3.17, SimpleJWT, drf-spectacular (OpenAPI)
- **Frontend:** React 19 + TypeScript + Vite, Tailwind CSS, TanStack Query, Recharts
- **Database:** PostgreSQL 17
- **Infra:** Docker Compose (local, home-network access — no cloud)
